# Güvenlik Politikası

## Desteklenen Sürümler

"Kanallar" projesi sürekli olarak geliştirilmektedir ve güvenlik güncellemeleri yalnızca en güncel ana sürüm için sağlanmaktadır. Olası güvenlik zafiyetlerinden korunmak için projenin her zaman en güncel sürümünü (GitHub `main` dalı veya son sürüm etiketi) kullandığınızdan emin olun.

| Sürüm   | Güvenlik Desteği   |
| ------- | ------------------ |
| 1.4.x   | :white_check_mark: |
| < 1.4   | :x:                |

## Güvenlik Açığı Bildirimi

Projede bir güvenlik açığı bulduğunuzu düşünüyorsanız, sistem güvenliğini tehlikeye atmamak adına bu durumu **herkese açık bir "Issue" (Hata Kaydı) olarak paylaşmayın**. Bunun yerine "Sorumlu İfşa" (Responsible Disclosure) kuralları çerçevesinde doğrudan bizimle iletişime geçin.

**Nasıl Bildirebilirsiniz?**
* **Tercih Edilen Yöntem:** GitHub deposundaki **Security** sekmesinde yer alan "Private Vulnerability Reporting" (Gizli Güvenlik Açığı Bildirimi) özelliğini kullanarak gizli bir bildirim oluşturabilirsiniz.
* **Alternatif Yöntem:** Doğrudan [Discord Sunucumuz](https://discord.gg/WZ8xkMmw2A) üzerinden sunucu yöneticilerine özel mesaj yoluyla ulaşabilirsiniz.

**Bildirim Süreci ve Beklentiler:**
1. **Teyit:** Raporunuz ulaştıktan sonra en geç 48 saat içerisinde inceleme başlatılır ve size dönüş yapılır.
2. **Değerlendirme:** Bildirilen açık doğrulanırsa, etkinin boyutu tespit edilir ve çözüm süreci planlanır.
3. **Çözüm:** Yama (patch) geliştirilip GitHub üzerinden yeni bir güvenli sürüm yayınlanana kadar süreç gizli tutulur.
4. **Kapanış:** Açık başarıyla kapatıldıktan sonra (ve eğer isterseniz) katkılarınızdan dolayı sürüm notlarında size teşekkür edilir.
